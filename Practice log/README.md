# 벨리댄스 연습일지 (Belly Dance Practice Log)

영상을 업로드하여 구간별로 정지하고 교정할 동작을 타임스탬프와 함께 기록할 수 있는 동작 분석 및 피드백 일지 웹 애플리케이션입니다.

---

## 실행 방법

### 방법 1. 간편 실행 (권장)
- 폴더 내 `실행하기.bat` 파일을 더블 클릭하면 로컬 서버가 시작되고 웹 브라우저가 자동으로 열립니다.

### 방법 2. 직접 열기
- `index.html` 파일을 더블 클릭하여 크롬(Chrome)이나 엣지(Edge) 브라우저에서 바로 열 수 있습니다.

---

## 주요 기능 안내

### 1. 영상 재생 및 동작 분석 특화 기능
- **영상 파일 로드**: MP4, MOV, WEBM 등의 연습 영상을 드래그 앤 드롭하거나 파일 선택 버튼으로 불러옵니다.
- **프레임 단위 미세 탐색**:
  - `-0.1s`, `+0.1s`: 0.1초 단위(프레임별)로 골반이나 팔 각도 미세 확인
  - `-1s`, `+1s`: 1초 단위 전후 이동
- **배속 조절**: 0.25배속, 0.5배속, 0.75배속, 1.0배속, 1.25배속 슬로우 모션 재생
- **거울 모드 (좌우 반전)**: 안무 및 동작을 거울처럼 보며 점검할 수 있는 원클릭 반전 모드
- **A-B 구간 반복 (Repeat Loop)**:
  - 어려운 콤비네이션이나 루틴의 시작점(A)과 끝점(B)을 지정하여 무한 반복 연습 및 분석

### 2. 타임스탬프 피드백 기록
- **실시간 캡처 및 등록**:
  - 영상 재생 중 고치고 싶은 순간에 `현재 시점 피드백 작성` 버튼을 누르거나 단축키 `M`을 누르면 영상이 멈추고 해당 시점의 프레임이 자동 캡처됩니다.
- **부위별 태그 분류**:
  - 골반/힙, 상체/가슴, 팔/손끝, 시선/표정, 코어/자세, 박자/템포, 기타
- **피드백 내용 입력**:
  - 교정점 (문제 동작 및 보완할 점)
  - 체크포인트 (동작 시 머릿속으로 상기할 큐 포인트)
- **개선 상태 관리**:
  - `보완 필요` vs `수정 완료` 체크 기능
- **구간 확인 재생**:
  - 피드백 카드에서 `구간 확인` 버튼을 누르면 해당 타임스탬프 전후 3초를 자동으로 재생하여 교정 상태를 바로 대조할 수 있습니다.

### 3. 일지 및 세션 관리
- **연습일지 보관함**: 날짜별, 루틴별로 여러 개의 연습일지를 작성하고 보관
- **오늘의 총평 및 과제**: 연습 후 잘된 점과 다음 과제를 기록 (입력 시 자동 저장)
- **요약 복사**: 작성된 모든 타임스탬프 피드백과 총평을 메신저나 메모장에 전송하기 좋은 텍스트 포맷으로 클립보드에 복사
- **리포트 인쇄**: 인쇄 및 PDF 저장에 최적화된 리포트 출력 지원
- **데이터 백업/복원**: 브라우저 로컬 데이터(IndexedDB)를 JSON 파일로 안전하게 내보내기/가져오기 가능

---

## 키보드 단축키
- `Space`: 영상 재생 / 일시정지
- `M` 또는 `N`: 현재 시점 피드백 작성창 열기
- `[` / `]`: 0.1초 뒤로 / 앞으로 이동
- `←` / `→`: 1초 뒤로 / 앞으로 이동
- `ESC`: 열려 있는 모달 또는 서랍 닫기
